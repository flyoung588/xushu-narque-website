Physical Scarcity

Which constraints remain necessary to machine production but cannot scale at software speed?

Five questions

  1. Will the machine economy still need it?
  2. Can supply expand quickly?
  3. Can technology substitute it?
  4. What is actually scarce: equipment, location, access, time, capacity, or rights?
  5. Does it create current economic value or Reality value?

Production scarcity

Energy, facilities, materials, equipment, permits and delivery access that directly constrain throughput.

Verification scarcity

Measurement, experiments, sites, samples, time and lawful access that create auditable Reality evidence.

This frame does not imply that NARQUE owns these assets.
